# Assignment-Animation

# 🎬 CSS Animations Showcase

An interactive, creative web project demonstrating various **CSS3 keyframe animations**, transform properties, and smooth UI transitions built using pure HTML and CSS[cite: 5].

## ✨ Features

* **🎨 Property Transitions & Keyframes:** Showcases multiple core animation types including color shifting, vertical translation, full 360-degree rotation, scaling (pulse effects), and opacity fading[cite: 5].
* **🔄 Spinner & Loader Effects:** Features a custom CSS rotating border loader animation[cite: 5].
* **📐 Complex Motion Paths:** Includes bounded square-path movement animations and a staggered Google-style multi-dot bouncing loading sequence using custom animation delays[cite: 5].

## 📂 File Structure

* `Animation.html` - The standalone HTML file containing the complete layout structure, flexbox container arrangements, and comprehensive embedded CSS keyframe rules[cite: 5].

## 🚀 How to Use

1. Download or clone the repository.
2. Open `Animation.html` in any modern web browser to view the live animated elements and loading sequences in action[cite: 5].
